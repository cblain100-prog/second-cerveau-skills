# Skills — Second cerveau (Entrepreneurs 2.0)

Les deux skills à installer pour ton second cerveau Claude Code :

| Skill | Rôle |
|---|---|
| **onboarding** | Construit ton second cerveau sur-mesure (interview adaptée à ton métier). Lance-le avec `/onboarding`. |
| **save** | Range automatiquement ce qui s'est dit en fin de session. Lance-le avec `/save`. |

## Installation (2 minutes)

1. **Télécharge** les deux fichiers :
   - [`onboarding-skill.zip`](onboarding-skill.zip?raw=1)
   - [`save-skill.zip`](save-skill.zip?raw=1)
2. **Dézippe-les** : tu obtiens deux dossiers, `onboarding` et `save`.
3. **Glisse** ces deux dossiers dans le dossier `.claude/skills/` de ton second cerveau. Au final tu dois avoir :
   - `.claude/skills/onboarding/SKILL.md`
   - `.claude/skills/save/SKILL.md`
4. Ouvre Claude Code, tape `/` : tu dois voir `/onboarding` et `/save`.

> Le guide complet (avec captures et la routine de récap du soir) explique tout pas à pas.

Tu peux aussi parcourir le contenu des skills directement dans les dossiers [`onboarding/`](onboarding/) et [`save/`](save/) de ce dépôt.
